# Excursión a Lauterbrunnen

Página web desarrollada con HTML, CSS y JavaScript sobre una excursión a Lauterbrunnen, Suiza. Incluye una descripción del destino, galería de imágenes interactiva, itinerario de actividades, cotizador de presupuesto, formulario de reservación y sección de reseñas. El sitio utiliza un diseño moderno responsive con efectos de transparencia, barra de navegación flotante e interactividad mediante JavaScript.

## Características

- Navegación entre las diferentes secciones de la página
- Barra de navegación fija
- Diseño moderno con transparencias, sombras y efectos al pasar el cursor
- Estructura semántica del contenido
- Galería con visor modal al hacer clic en las imágenes
- Filtro en tiempo real sobre la lista de actividades
- Calculadora de cotización con paquetes y servicios adicionales en quetzales
- Formulario de reservación con validación de campos y mensaje de confirmación
- Sección de reseñas con testimonios aleatorios

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
