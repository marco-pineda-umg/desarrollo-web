# Projecto React + Vite con Bootstrap

Tarea número 2, tienda en linea desarrollada con React y Bootstrap

---

## Características

- Pagina responsiva: se adapta facilmente a escritorio o pantallas de telefonos.
- Componentes de bootstrap: para un mejor despliegue de la información.
- Componentes de react: para modularización de la pagina, mejor estructura y funcionamiento del DOM

## Componentes de React

- Nav.jsx
- Hero.jsx
- Itemcard.jsx
- Carousel.jsx
- Testimonial.jsx
- Footer.jsx

## Componentes de Bootstrap

Se utilizaron los siguientes componentes

- Barra de navegación: barra de navegación responsiva.
- Tarjetas: productos y testimonios.
- Modals: despliegan informacion detallada de cada producto.
- Carrousel: despliegue de imagenes en la sección de galeria.
